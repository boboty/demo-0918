# 来源清单 · Source Inventory

> 本文件回答：**我们手上有哪些可核验的公开来源？**
>
> **本文件不做裁决。** 只登记来源、摘录原文、标注疑点。
> 不对项目状态、数字真伪、来源优先级做最终判断。

## 怎么读

| 字段 | 含义 |
| --- | --- |
| Source Candidate ID | 来源编号（`SRC-Cxx`，C = candidate） |
| 来源类型 | 年报 / 交易所公告 / 政府公示 / 企业官网 / 招投标 / 研究机构 / 媒体 |
| 级别建议 | 依产品定义第 7 节映射为 A / B / C / D（**建议值，非裁决**） |
| 核实状态 | ✅ 本线独立复核通过 / 子代理取回原文 / ⚠️ 仅搜索结果摘要、未打开原文 |
| 涉及项目 | 对应 `PRJ-Cxx` |

**关于"级别建议"**：产品定义第 7 节把来源分为 A/B/C/D 四级。此处给出的是**映射建议**，
用于让后续规则有输入可判；它不是判定结果，规则冻结后应重新裁定。

**关于"核实状态"**：本清单严格区分三种情况，研究价值完全不同——
本线**自行取回并比对过**、子代理取回原文、以及**仅有搜索引擎摘要**。
第三种一律视为线索，不得作为关键事实的唯一来源。
