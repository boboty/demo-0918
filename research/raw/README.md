# raw/ · 来源原文摘录留档

本目录存放从公开来源抓取的**短摘录**留档，用于支撑 `../source-inventory.md` 中的记录。

## 规则

- **只放短摘录，不放全文转载。** 每条不超过必要长度，通常一到三句。
- 每个文件以 Source ID 命名（如 `SRC-C01.md`），与 `../source-inventory.md` 对应。
- 必须记录：URL、发布日期、抓取日期、来源类型。
- 必须标注该页面是**已打开原文**还是**仅搜索结果摘要**。
- 不从本目录做任何事实裁决；裁决性表述一律不写。

## 为什么需要留档

公开页面会失效、改版、下架。留档让后续核查能区分：

- "当时原文确实这么写" 
- "来源已失效，无法复核"

这两种情况对研究结论的意义完全不同。
