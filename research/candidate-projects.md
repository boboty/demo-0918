# 候选项目清单 · Candidate Projects

> 本文件回答：**现实世界中有哪些足够复杂的真实储能项目，值得用作产品验证？**
>
> **本文件不做裁决。** 记录事实性披露与疑点，不判定项目最终状态、
> 不判定数字真伪、不判定两个名称是否同一项目。

## 怎么读

| 字段 | 含义 |
| --- | --- |
| Candidate Project ID | 项目编号（`PRJ-Cxx`） |
| 原始项目名称 | 来源中的原始写法 |
| 其他来源中的名称 | 不同来源的不同叫法，**并列保留，不合并** |
| 储能类型 | 独立储能 / 配建储能 / 未知（**按原文表述，不推测**） |
| 各来源披露的 MW / MWh | 逐来源列出，保留原文单位 |
| 各来源披露的投资金额 | **保留原始表述**（计划投资 / 协议 / 预算 / 资本开支 / 转固 / 总投资） |
| 各来源声称的阶段 | 原文措辞 |
| 来源列表 | 对应 `SRC-Cxx` |
| 当前疑点 | 需后续核查的问题 |

## 三条不可违反的记录纪律

1. **MW 与 MWh 分列，不得合并。** 两者是不同物理量，不得出现"项目规模 200MWh"这类写法，
   也不得把两个数字相除得出"储能时长"后当作披露事实。
2. **投资金额必须保留原始口径。** 计划投资 / 协议投资 / 总投资 / 项目预算 / 资本开支 / 已转固资产
   不是同一件事。**EPC 中标价 ≠ 项目投资额**，**股权收购对价 ≠ 项目投资额**，
   **框架采购额 ≠ 项目装机**。
3. **不推测、不补全、不倒推。** 不根据 MW/MWh 推投资额，不推测未披露的经营结果，
   不把"拟""计划""预计"写成已发生，不为让时间线完整而反推补全缺失阶段。

资料不足时写「**暂无公开可确认证据**」。

## 关于"疑似同一项目"

允许：「疑似同一项目，待规则判定」「存在口径差异可能」「需进一步确认」。
不允许：「确认为同一项目」「该项目建设状态为已投运」「X 亿元为正确值」。

# 四、研究中普遍难以获得的信息

以下缺口**跨越三家平台、具有普遍性**，是后续产品必须能诚实表达的"未知"。

## 1. 项目级投资额普遍不可得

- **龙源电力**：未在交易所层面按项目披露任一独立共享储能电站的投资额。
  唯一交易所级储能金额披露是 SRC-C17 两个风电项目的**配建储能工程科目**。
- **三峡能源**：6 个候选项目中，**除昔阳（环评公示）与格尔木（土地划拨，成交价 0 元）外，
  均无以一手文件形式披露的项目总投资额**。
- **中国电力**：多数项目投资额缺失；已有的几个（祁东、双牌、灌西盐场）**全部存在口径争议**。
- **普遍陷阱**：EPC 中标价、股权收购对价、框架采购额**都不是项目投资额**，
  但在二手报道中经常被写成"投资"。

## 2. 经营结果几乎完全不可得

本池中**没有任何一个项目**有可确认的公开经营数据（发电量、收入、利用小时、调用次数）。
集团层偶有汇总口径（如龙源「配建储能累计放电量3.44亿千瓦时」），但**无法下沉到项目**。
→ **"经营结果未知"不是个别现象，而是常态。**

## 3. 项目主体 / SPV 披露不稳定

- 披露了：PRJ-C03（舟山龙源新能源）、PRJ-C12（昔阳县斯能光伏发电）、
  PRJ-C13（三峡新能源格尔木发电）、PRJ-C06（海南国能龙源）、PRJ-C07（中卫龙源）。
- **未披露**：PRJ-C02、PRJ-C05、PRJ-C08、PRJ-C09、PRJ-C10。
- **披露但互相矛盾**：PRJ-C01（三个不同主体指向）。
- **承建方 ≠ 业主**：新源智储承建的多个项目**未披露任何业主或 SPV**。

## 4. 储能类型（独立 / 配建）经常没有原文表述

多个项目只写「电网侧电化学储能项目」「储能调峰项目」「共享储能电站」，
**既不写"独立储能"也不写"配建"** → 只能按原文记录为待核实，**不可推测归并**。

## 5. 同名/近名项目与"接入变电站名"混淆

- **接入变电站名被当成项目名**：彭家湾（PRJ-C19）、舒家塘（PRJ-C20）——这是本轮最有价值的发现之一。
- 同一企业在同一省份有多个同规模项目（龙源河南公司：许昌 vs 洛阳，均为 200兆瓦/400兆瓦时）。
- 名称相似但分属不同集团（中电控股 CLP vs 中国电力 02380；中国电建 vs 中国电力）。

## 6. 上市公司年报不提供项目级储能数据

三家平台中，**三峡能源年报只给"其他（独立储能）"合计行**，
**龙源电力年末装机分类未单列新型储能**，
**中国电力将储能并入"储能及其他"合计口径**。
→ 若产品期望用年报做项目级事实还原，**这条路径在公开数据上不成立**。

## 7. 检索环境限制（诚实说明）
